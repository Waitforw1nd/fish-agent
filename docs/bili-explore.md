# B 站探索（L0 / L1）

探索默认关闭，启用后每 30 分钟最多读取配置的 UP 主投稿和少量关键词搜索，每次最多 30 个候选。仅使用租户自己的登录账户；自动化访问可能受平台协议限制。活动时段使用桥接主机本地时间。配置的 UP 主来自 B 站订阅设置。浏览及草稿数量受最近 24 小时滚动窗口的服务端硬上限约束，不在自然日零点清零。

L0 保存视频日记和可用字幕依据。无字幕时只记录未能理解，不生成草稿。L1 需要明确确认规则与风险；模型通过租户 Agent 的人设和 Relay 生成文本，外部文本作为不可信数据且不提供工具。草稿保留字幕证据，24 小时后失效；编辑时强制保留“【AI生成】”。三次连续拒绝降回 L0。批准仅改变本地状态，本功能没有发布、评论、点赞或私信路径。

字幕读取或模型生成期间，停用、风控、冷却、活动时段及浏览上限会在下一阶段重新检查；视频详情、WBI 签名前置读取、播放器和字幕下载也在每次实际请求及重试前检查，旧轮次不会因暂停后立即恢复而继续。草稿写入事务还会核对最新级别、确认状态和滚动窗口限额。已经完成并写入日记的浏览及已发生的模型 Token 仍计量；若下调浏览上限使本次访问超限，不再启动下一阶段生成，已返回的摘要或草稿也不保留。上限为 1 时允许首个视频完成生成；从 2 降至 1 且本次仍在限内也允许完成。失去生成资格不产生草稿计数。已开始的模型请求不因配置变化被追溯取消或免计量。

候选发现也在每个 UP 投稿或关键词请求前复核启用、风控、冷却和活动时段。运行中删除任一旧关键词或已关注 UP、停止桥接或启动失败清理，都会撤销当前轮次。重新加入 UP 或立即恢复时，旧候选和在途生成结果仍会被拒绝。已经发出的只读请求可完成，已经发生的浏览仍记录和计量。

一次探索轮次从等待历史计量补报之前就固定进程内状态代次。暂停、风控或使在途工作失效的配置变化会废弃旧轮次，即使立即恢复，历史计量补报结束后也会退出该轮。恢复后的新轮次重新检查条件，已发生的浏览仍保留日记和计量。重启时不存在存活的旧异步任务，因此代次无需持久化。

轮次在后续请求、模型调用和草稿入库前持续复核桥接运行、登录及监听状态。登出立即撤销旧轮次。监听插件每次启停写入随机生命周期版本号，关闭后在同一毫秒重新开启也会撤销旧轮次；旧格式状态文件使用文件修订信息兼容。无关配置更新允许当前轮次继续。

云端和独立桥接均强制 `security.readOnly=true`，环境变量、配置覆盖和运行时修改都不能开启发布。旧 OneBot 评论、私信、弹幕和点赞动作在桥接层及 HTTP 层拒绝；私信轮询也不提交远端已读标记。只读模式唯一允许的 POST 是两个固定的登录凭据刷新端点。底层 `BiliApi` 默认同样只读；历史写协议测试显式关闭此层限制时，也只能请求 `127.0.0.1` 或 `[::1]` 的本机 fixture，不能携带 URL 用户信息、访问远程目标或自动跟随写请求重定向。

字幕与封面只接受配置的 API/字幕来源或 HTTPS 的 `hdslb.com` CDN；短链逐跳限制 B 站域名。响应流在读取过程中执行字节限额，超限立即取消，不等待完整下载。

直播弹幕服务器列表同样视为不可信输入：只接受合法的 `bilibili.com` 域名及有效端口，拒绝内网/IP、伪域和 URL 注入；只有直播 API 本身显式配置数字回环时，才允许数字回环假 WebSocket。未来平台若更换域名，需要评估并更新允许列表。

检测到平台风控后暂停，人工在可信环境完成验证并清除状态后，再冷却 24 小时。状态、去重、日记、草稿与待上报计量存储在租户桥接数据目录的 `explore.json`。成功读取详情的视频和实际入队草稿分别上报 `bili.video.browsed` 与 `bili.comment.drafted`，使用幂等键和持久队列重试，模型 Token 由 Relay 计量。一次成功的视频详情读取对应一条日记及一个浏览事件。后续播放器失败或暂停中止字幕读取时，仍持久化这次浏览并占用滚动窗口限额，字幕可用性保留为未知。详情读取本身失败时没有浏览事件。浏览事件以日记记录 ID 标识一次操作，补报重试保持原 ID。视频离开有界去重缓存后再次浏览使用新的事件 ID。连续拒绝按实际审核顺序判断并持久化。

桥接 `/admin/explore` 提供读取和配置，`/admin/explore/drafts/:id/edit|approve|reject` 提供审核。云端租户路由在 `/api/tenants/:id/bili/explore` 下，并通过现有租户权限及桥接管理令牌保护。独立桥接可注入 `exploreGenerate` 与 `exploreMeter` 回调；未提供生成回调时只记录日记。云端使用仅回环访问的 Agent 内部端点和 Relay，令牌不可从面板配置。

生产传输由 `src/explore-services.js` 创建，拒绝 HTTP 重定向；本地 Agent/Relay 响应按原始字节流限制为 64 KiB，超限立即取消，解析错误不回显响应内容。计量只有收到完整 Relay 数量回执才从持久队列删除。故障测试和云端集成测试使用同一传输实现。

桥接运行期间，独立计量任务在启动约一分钟后执行，后续每 30 分钟加至多一分钟抖动重试已有事件。关闭探索、关闭监听或 B 站登录失效时，仍会向本地 Relay 补报已发生的用量。并发补报共用同一投递过程，保留原幂等键。停止桥接会清除后续定时任务，已开始的本地补报请求受 30 秒超时约束，未获确认的事件留待下次启动重试。
