# 阶段二：Agent 设置与扩展服务

完成时间：2026-10-29。

- `AgentSettingsService` 统一在线回环配置和离线原子写入，使用共享配置编解码器与云端 guard。写入时强制关闭空白名单放行、跨会话发送和私网图片地址；仅允许白名单内的映射字段整体替换，扩展配置必须使用专用接口。
- 同源接口覆盖配置、人设模板、SillyTavern JSON/PNG 角色卡预览与导入、联系人、暂停、会话、消息、记忆、技能和提示词预览。记忆读取合并群友备注，编辑时保留未提交修改的备注并兼容印象对象。
- 扩展服务支持管理员 ZIP 安装、公共插件库、批量下发与移除、内置扩展屏蔽和恢复。管理员目录按实例隔离；在线安装加载失败时恢复旧目录与屏蔽表并重新加载。插件库的部署数量从租户实际安装目录统计。
- Windows 安装、替换及回滚目录时，对文件句柄释放造成的暂时性移动失败做最多两秒的有界重试；仅在源目录仍存在且目标不存在时重试。插件异常向 API 返回固定诊断，避免将异常中的凭据回显。
- 扩展开关和参数修改按清单声明的安全标量 schema 验证；配置、技能及插件列表隐藏敏感字段和敏感默认值。扩展变更、技能编辑和快照恢复按一致的锁顺序串行执行。
- 技能列表在线合并核心八类工具、可用性与诊断；离线提供八类目录并标记 `availabilityKnown: false`。会话、消息、记忆操作、暂停和完整提示词预览需要实例在线；离线仍可编辑配置、人设及安装扩展，角色卡预览不依赖运行进程。

验证：`node --test packages/cloud-manager/test/agent-extensions-view-api.test.mjs` 连续运行 8 次通过，覆盖真实核心进程的在线配置、记忆备注、工具诊断、插件坏包回滚，以及离线配置、JSON/PNG 角色卡、权限、密钥脱敏和插件库部署统计。`node test/coverage-http.mjs` 核心 HTTP 覆盖通过 116 项；`node test/skill-test.mjs` 通过 24 项；`node test/tools-skill-audit.mjs` 通过 34 项。完整仓库回归与环境限制记录在阶段五。
