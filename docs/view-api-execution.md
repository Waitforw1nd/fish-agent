- 当前 Node.js：v24.22.1。
- npm CLI 位于 `.tools/node/node_modules/npm/bin/npm-cli.js`（11.19.1），后续通过 `node .tools/node/node_modules/npm/bin/npm-cli.js ...` 执行标准 npm 脚本。
- 仓库初始已有大量修改，最终验证同时涵盖既有回归和本次新增功能；200 个变更 JS 文件语法检查通过，不表示这些文件全部由本轮新增。
- 真实 QQ 扫码、真实上游凭据和生产容器环境不作为伪造通过项；自动化与真实部署验收分别记录。
- 最终云端回归包含 Gateway 脱敏、Agent IPC 就绪回执及并行测试端口隔离；面板在全部后端修改完成后再次通过完整套件。
