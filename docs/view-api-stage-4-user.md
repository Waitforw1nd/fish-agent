# 阶段四：用户工作台

完成日期：2026-10-29。

实例卡片与实例详情展示四步开通就绪度；白名单不足时提示不会回复，并提供直达配置的链接。单实例工作台提供概览接入、群聊白名单、人设与角色卡、响应档位与能力、会话记忆与备份五个页签；QQ Agent 也可通过独立入口在多个实例间切换。QQ 登录沿用已有二维码代次检查、事务式内核切换与轮询清理；B 站使用共享组件配置四类订阅和监控目标。

渠道页支持套餐允许模型选择、未保存自定义上游连接探测及模型建议。钱包页显示审核说明和收支流水，并提供套餐续费；日志页显示平台提供的按日和会话归因费用。viewer 界面只读，operator 不能修改仅 owner 可操作的渠道、充值和备份。退出或切换页签前对未保存的配置提供确认。
