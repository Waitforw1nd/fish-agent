# 阶段四：管理员控制台与应用壳层

完成日期：2026-10-29。用户视图的独立记录见 `view-api-stage-4-user.md`。

## 已实现的页面与操作

- 管理员默认进入运营总览；侧栏只显示当前工作区导航，可切换用户视角并返回管理台。保留旧租户地址，新增单实例五个分区，底部提供自助改密。
- 运营总览展示实例、用户、待审充值、用量与驱动健康；充值审核支持状态和租户筛选、备注确认、必填原因驳回。
- 租户列表支持名称、slug、QQ 号、所属用户、状态与套餐筛选。创建可指定用户、套餐、初始服务天数。
- 用户管理支持搜索筛选、实例计数、最近登录、禁用/启用、重置密码与角色修改；最后活跃管理员的禁用/降权在界面和后端同时受保护。
- 实例中心提供启停、重启、续费换套餐、暂停/恢复资格；通道页复用 QQ/B 站组件，配置和扩展页复用 Agent Studio 与扩展管理组件。
- 中转与计费页新增人工充值/扣款及流水。运维页包含进程分类日志、可选每五秒刷新、成员协作、加密快照创建/恢复和实例审计。
- 插件中心可上传公共 ZIP 包、删除库条目、选择多实例分发/升级/移除，展示真实安装数量、各实例当前安装状态，以及批量操作成功和失败原因。
- 平台设置支持公共上游、LLBot 授权保存和清除，以及驱动预检。审计页按租户、操作人和动作查询。

## 实现与兼容

新页面位于 `panel/views/admin/`，复用原 DOM、弹窗、主题及同源请求层。外部名称、日志、审核说明和错误均通过文本节点呈现。已有 `views/tenants.js`、`views/users.js` 的入口继续可用；旧 Hosting/Relay 独立视图回归测试保留。

样式集中在 `panel/styles/workspace.css`，沿用现有深海青主题，支持亮/暗主题、横向可滚动表格、窄屏单列布局、键盘焦点与减少动画偏好。表单关闭时清除密码输入；只保存用户本次输入的秘密值，空上游 Key 不覆盖已有密钥。

应用壳层接入未保存配置检查。取消跨页导航后恢复原地址和表单，不重复弹出确认；对应应用挂载测试覆盖取消与确认两条路径。
