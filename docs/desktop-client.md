# Desktop pet client

The `packages/desktop-pet` package is a separate Electron application. Install its declared dependencies from a trusted package source, then run `npm start` from that directory. `npm run dist` uses electron-builder for Windows NSIS (and can target macOS DMG on macOS), after its `predist` runtime check passes. No installer is generated by this change.

In the cloud panel, create a desktop pairing code, enter the service HTTPS origin and code in the pet, and connect. HTTP and unencrypted WebSocket are allowed only on loopback for local development. Device credentials, pending messages and the replay cursor are encrypted with Electron safeStorage in the app's user-data directory and remain in the main process; the renderer receives display data and a fixed command API. Unavailable system encryption is an error; there is no plaintext fallback. The tray menu can show or quit the pet. Drag the fish to move the window. “清除本机配对” removes local credentials; revoke the device in the cloud panel to invalidate it remotely.

The client reconnects with jittered exponential backoff (up to a 30-second base), resumes from its last saved sequence, and preserves message IDs. Revocation stops automatic reconnection. Restarted attempted sends, ACK timeouts, recovery gaps and long disconnections require an explicit retry/discard decision; retries may duplicate server work beyond its deduplication window. Save failures stop the connection before advancing the cursor. The current server retains at most 200 replies/24 hours and 1000 deduplication keys, so this does not guarantee complete history or indefinite exactly-once delivery. See [gateway followups](desktop-pet-gateway-followups.md).

The current UI sends **text only**. It can display received text, face/reply labels and bounded embedded PNG/JPEG/GIF/WebP data without loading remote image URLs; there is no image picker or image-send/face/reply button. Model content is inserted as text or validated image data, never HTML. The two built-in character packs are static geometric PNGs. The interface continuously displays “AI 生成”.


For offline monorepo development where the core package already has its dependencies installed, run `npm run dev` in `packages/desktop-pet`: it uses the package's Electron and `ws` when available, and otherwise uses the existing core artifacts. This fallback is restricted to the explicit development launcher and unpackaged applications; packaged builds require their own declared dependencies. Use `npm ci` when the package registry or a complete npm cache is available.

Release blocker found on 2026-11-03: the lockfile still pins Electron 33.4.11, which reached end of support on 2025-04-28 according to the [official schedule](https://releases.electronjs.org/schedule). The attempted upgrade was blocked by network access (`EACCES`), so neither the dependency declaration nor lockfile was fabricated or partially updated. `predist` now rejects this runtime; this review's minimum release baseline is stable Electron 45. Update the dependency and lock together, install the matching version, recheck the current support/patch status and repeat the native security/storage acceptance before packaging. A passing Node test suite or compatibility smoke test does not resolve this blocker. See [acceptance results](v1.0-acceptance.md).
