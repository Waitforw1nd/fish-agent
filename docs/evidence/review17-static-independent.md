# 第 17 轮独立静态核查

2026-11-03。本记录为静态审查与根检查，不代表本轮 `test:all` 已执行或通过；本轮最终全量以主审的原始日志为准。本次未连接真实 QQ 或 B 站。

- 根 `scripts/run-tests.mjs --all` 顺序执行 B 站桥接、云管理后端、云管理面板、核心 `test:all`、桌宠、LLBot TypeScript 检查和 LLBot Vitest；遇失败即停止。核心 `test:all` 包含主测试、headless、多入口、五组 coverage、checker 和六个额外契约文件。LLBot 的 `vitest.config.ts` 只包含 `test/unit/**/*.test.ts` 和 `test/webui/**/*.test.ts`，真实平台 OneBot、Milky、WebQQ 测试目录不在此命令内，也不构成真实服务验收。打包、桌宠 acceptance、真实账号和真实 VPS 均不在该入口中。
- 静态查找发现上述正常测试目录无 `.only`；存在的条件跳过包括 Windows 上 2 条 Linux 进程组测试及 1 条 POSIX SIGTERM 测试、桌宠文件符号链接权限不足、未安装 jsdom 的 UI/白名单交互、缺 ffmpeg 的 GIF 转码和未加载技能的 4 条检查。实际是否发生应以本轮全量日志为准，不能单凭源码当作已执行或已跳过。
- 上一轮 Windows 全量日志明确记录 4 项平台/权限跳过（上述 2+1+1），以及 5 项环境/真实系统跳过：安装包缓存哈希、两项 SnowLuma 对齐与版本、QQ 打包归档哈希、真实系统 QQ 进程检测。另有 4 条危险路由排除：打开数据目录、打开 SnowLuma 文件夹、打开 SnowLuma WebUI、停止便携 QQ。它们都不计通过。该轮 HTTP 声明路由 93、覆盖 81、排除 4，可测覆盖 81/89；它是声明路由触达统计，不是所有输入或业务分支覆盖率。本轮结果必须从本轮日志重新统计。
- LLBot 不属于常规 Vitest 入口的真实平台测试另显式跳过踢人、禁言、退群、删好友、修改状态/权限、重启、配置修改，以及需要第三方账号或特殊数据的场景；未运行的整个目录不能因有跳过标记而算通过。
- 根检查仅验证 Node 版本、若干 package 脚本存在和 `run-tests.mjs` 语法；它并不执行测试、检查所有脚本的语法、验证面板 package 脚本或证明安装/打包可行。首次调用因 PATH 中无 node 失败；设置 `D:\tool\node` 后执行 `npm run check`，Node v24.21.0 退出 0。分别见 [首次](review17-core-root-check.txt) 和 [重试](review17-core-root-check-path.txt)。
- 检查 Git 枚举的已修改及未跟踪 Markdown（排除证据目录及已删除文件），37 个现存文件的 395 个普通内联相对目标均存在，见 [结果](review17-core-links.txt)。这不检查外链、锚点、引用式链接或非 Markdown 引用；Git 无法读取用户 ignore 文件且提示一个无关路径异常，范围受其枚举结果限制。删除的 `view-api-*` 文档名称在现存非证据 Markdown 的文本搜索中未发现引用。
- 阅读非 QQ 面板入口和 B 站探索组件：渲染采用 DOM 文本节点，配对二维码限制 PNG data URL，入口键来自固定表，异步刷新支持取消与序号防陈旧覆盖；只读状态阻止变更；批准草稿界面明确说明不发布。此为静态检查，不替代真实浏览器和平台验收。
- 文档总体将本地模拟与真实平台、桌宠实机和打包门禁分开；`docs/testing.md` 开头“仅将外部 QQ、B 站与大模型服务替换为本地 Fake 模块”措辞偏绝对：套件还使用 DOM 桩、临时文件和其他边界注入。应理解为集成链路的概括，而不是所有测试仅替换这三类外部服务。历史验收记录各自描述当轮结果，不能直接作为第 17 轮结果。
