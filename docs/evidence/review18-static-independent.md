# 第 18 轮独立核查

2026-11-03。主审与三个指定的 `gpt-6.1-terra/high` 子代理按域核对 Git 未提交改动和未跟踪实现、测试、文档。本轮没有发现需要修复的新确定性问题，未修改产品代码或 Kimi 官方 Bot 文件。完整测试和模拟链路的结果以本轮原始日志及清单为准，不能以此前 17 轮的成功记录替代。

- **安全与隔离**：检查租户会话/角色、按匹配路由校验 CSRF、入口生命周期队列、QQ 官方会话与 OpenID 归因、桌宠配对和吊销、成员记忆/备注、Relay 模型列表及错误脱敏。桌宠会话与 QQ 官方会话仍通过号段或带作用域前缀的会话标识分开；官方裸成员 OpenID 按已确认的官方入口上下文解释。
- **计量**：检查客户端事件的租户绑定、入口和 chatKey 一致性、客户端幂等键与服务端事件隔离、批次回滚、token 扣费/账本/计量同事务、长流预留、空截断流释放预留，以及托管进程结束证据和 checkpoint。专项 41 项通过；端到端仍另行重跑。没有把客户端可上报的消息统计当作可信的货币扣费来源。
- **B 站**：检查所有桥接写动作的拒绝、平台/字幕/直播 URL 限制、会话世代和逐阶段撤销、暂停恢复、配置版本、字幕后续请求、日记与计量补报、停机登出凭据删除失败的报告。桥接与云端 B 站专项 117 项通过。审核批准仅改变草稿状态，不产生发布请求。
- **桌宠**：检查 contextIsolation、沙箱配置、主 frame/IPC 白名单、文本渲染、主进程安全存储、双游标回放、旧连接隔离、恢复失败上限、未确认消息与丢 ACK 查询、吊销、在线时长幂等及停机尾段。专项 104 项通过，1 项因 Windows 文件符号链接权限跳过；目录 junction 越界测试通过。素材测试验证两套项目生成的几何鱼占位图，没有 dsh-pet 角色素材。
- **核心与下载器**：核对路由、成员存储、旧副本删除、LLM 错误和启动日志、子进程退出状态、下载背压、重命名/异步写盘失败。核心专项 36 项通过、1 项 Windows SIGTERM 跳过，路由专项通过，下载器 59 项通过。
- **测试真实性**：检查根和核心测试编排、checker 的 fail/known/skip 语义、隔离子进程的退出码/信号/超时，以及模拟服务的实际调用和 teardown。正常测试/脚本目录扫描 196 个文件，没有 `.only` 或 `only: true`。条件跳过与真实平台目录排除仍需按本轮运行输出分别披露；危险 HTTP 路由不计入通过，声明路由触达比例不等同于分支覆盖率。DOM、计时器和故障边界替身不能证明原生 UI 或系统服务可用。
- **模拟链路边界**：OneBot 使用本地 WebSocket 替身；官方适配器用本地 HTTP/Gateway 替身，另有生产 prepare/start/stop 路由链路；桌宠使用真实客户端连接、Gateway、Headless、Relay 与假模型；B 站使用 FakeBili 和真实 Bridge/Agent/Relay。全部使用临时租户和测试数据，未连接真实 QQ/B 站。官方 Bot **只有 Gateway 事件/OpenID，没有 webhook**；当前验收手册不要求 webhook，因此不影响其规定的模拟验收，也不能声称 webhook 已通过。
- **文档和发布限制**：桌宠原生系统加密/沙箱、多屏、休眠、安装包/签名及 macOS 仍需实机验收；本轮没有重复用兼容模式代替安全验收。现有 Electron 33.4.11 仍被仓库最低 45 的打包门禁拒绝。本记录只核验本地版本和门禁，不声称重新验证了外部版本支持日程。历史歧义记忆/备注/账目仍需人工核对。
- **持久化限制**：网关待写在线区间在内存中，持续写入失败或强制退出仍可能丢失未结算用量；B 站远程读取与本地日记/计量落盘之间也没有跨服务原子性。托管运行缺乏可靠终止证据时不继续推算费用。这些已有边界不能被正常取消、重试和停止测试的通过覆盖。
- **清理**：重新核对了 28 个旧测试目录，全部位于工作区 `var` 且无重解析点；没有 `review16-*` 或 `review17-*` 残留目录。安全批量删除及显式单目录 `review9-bili-negative` 删除都被自动审批以 `blocked by policy` 拒绝，没有绕过拒绝。进程按本轮追踪核验，不杀无法确认归属的 Node。
